واجهة المدن والحساب الحديث (`hmomen.com`)

يعتمد موقع حقيبة المؤمن الحديث (`hmomen.com`) على واجهة RESTful عامة لجلب الدول والمدن وإحداثياتها عبر: https://hmomen.com/api/geolocation

  • • توفر البحث عن المدن بالاسم العربي (مثل "النجف" أو "الاسكان الصناعي") أو عبر رمز الدولة (IQ) أو معرّف المدينة (--city-id 65).
  • • تزود العميل بخط الطول (`longitude`)، خط العرض (`latitude`)، وإزاحة التوقيت بالميلي ثانية (`timezone_offset`).
  • • يحسب عميل الويب الحديث المواقيت التسعة محلياً باستخدام معادلات `PrayTimes` الفلكية، وهو ما يطبقه السكربت بدقة 100% كمسار احتياطي موسوم بوضوح.

المستوى 1 — البداية السريعة (مبتدئ) متطلبات التشغيل: Node.js 18+

التجهيز واستكشاف الدول والمدن

لا يحتاج السكربت إلى `npm install` أو أي مكتبة خارجية؛ فهو يعتمد حصرياً على واجهة `fetch` ووحدة `node:fs/promises` المدمجة في Node.js الحديث.

1. استعراض قائمة جميع الدول المتاحة: 
node fetch-hmomen-prayer.mjs --countries
2. جلب جميع المدن المسجلة لدولة محددة (مثل العراق IQ): 
node fetch-hmomen-prayer.mjs --country IQ
3. البحث عن مدينة بالاسم العربي لمعرفة الـ ID وإحداثياتها: 
node fetch-hmomen-prayer.mjs --search "النجف"
المستوى 2 — جلب وحساب المواقيت (متوسط) بمعرّف المدينة أو بالإحداثيات

طلب أوقات الصلاة مع الحماية الاحتياطية

يمكنك طلب أوقات الصلاة إما بتمرير رقم المدينة (`--city-id`) ليقوم السكربت بجلب إحداثياتها تلقائياً، أو بتمرير خط الطول والعرض وفارق التوقيت مباشرة:

1. جلب مواقيت مدينة النجف الأشرف (`--city-id 65`): 
node fetch-hmomen-prayer.mjs --prayer --city-id 65
2. جلب المواقيت بإحداثيات مخصصة (مثال: الناصرية / الإسكان الصناعي): 
node fetch-hmomen-prayer.mjs --prayer --timezone +3 --long 46.2785656 --lati 31.0109644
3. تحديد تاريخ معيّن ومنهج فلكي محدد (مثل `Makkah` أو `Tehran`): 
node fetch-hmomen-prayer.mjs --prayer --city-id 65 --date 2026-10-16 --method Jafari
المستوى 3 — التحكم بالشبكة والتحقق (متقدم) إدارة المحاولات وفحص المخرجات

تخصيص إعادة المحاولة والتحقق الآلي

في بيئات الخوادم، يمكنك التحكم بعدد المحاولات (`--retries`)، زمن الانتظار الأولي (`--delay-ms`)، أو إجبار السكربت على انتظار المصدر الرسمي فقط دون حساب بديل (`--retry-forever --no-fallback`).

1. حفظ المخرجات في ملف JSON ثم التحقق من صحتها آلياً: 
node fetch-hmomen-prayer.mjs --prayer --city-id 65 --output latest-prayer.json
node verify-prayer-output.mjs latest-prayer.json
2. وضع المراقبة المستمرة للمصدر الموثق فقط (بدون حساب محلي): 
node fetch-hmomen-prayer.mjs --prayer --city-id 65 --retry-forever --no-fallback --output official-only.json
3. إعادة توليد الدليل التقني آلياً بعد أي تعديل على الكود: 
node generate-line-by-line-doc.mjs

1. اليوم اليولياني المصحح بخط الطول (`julianDate`)

              
يحول التاريخ الميلادي `(year, month, day)` إلى عدد الأيام اليوليانية المتصلة، ثم يطرح longitude / (15 * 24) لضبط موقع الراصد.

            

            

              
2. موضع الشمس ومعادلة الزمن (`sunPosition`)

              
يحسب عدد الأيام منذ العصر الفلكي `J2000` (d = julian - 2451545.0)، ومنه يحسب الشذوذ المتوسط `g`، والطول المتوسط `q`، والطول البروجي المصحح `l`، وميل دائرة البروج `e`، ليستخرج الميل الشمسي (`declination`) ومعادلة الزمن (`equation`).

            

            

              
3. الزوال وزوايا الارتفاع الشمسي (`midDay` & `sunAngleTime`)

              
وقت الزوال هو 12 - equation. أما الشروق والغروب فيستخدمان زاوية الانكسار القياسية 0.833°، بينما يستخدم الفجر والمغرب والعشاء زوايا المنهج المختار.

            

            

              
4. معالجة العروض العليا (`adjustHighLatitudes`) ومنتصف الليل

              
يحمي الأوقات من قيم `NaN` في المناطق الشمالية/الجنوبية البعيدة عبر قاعدة `NightMiddle` (نصف الليل). وفي المنهج الجعفري يُحسب منتصف الليل الشرعي كمنتصف المسافة الزمنية بين الغروب وفجر اليوم التالي.
