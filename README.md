# بوابة واجهات أوقات الصلاة والتقويم الهجري — حقيبة المؤمن (GitHub Pages)

موقع ويب ساكن وتفاعلي متكامل جاهز للاستضافة المجانية على **GitHub Pages**، يجمع بين:
1. **حاسبة ومحاكي أوقات الصلاة الفلكي** المتوافق مع واجهات حقيبة المؤمن (`hmomen.com` و `hq.alkafeel.net`).
2. **الضبط التلقائي للتاريخ الهجري** وفق مواقيت الأهلة الصادرة عن مكتب سماحة المرجع الديني الأعلى السيد علي الحسيني السيستاني (`https://www.sistani.org/arabic/archive/26961/`).
3. **التغيير التلقائي اليومي للحديث الشريف** مع شرحه المفصل، وعرض الحدث الإسلامي المصادف لليوم الهجري.
4. **التحديد التلقائي للموقع الجغرافي** وحساب المواقيت التسعة بصيغتي 24 ساعة و12 ساعة.

## طريقة التشغيل على GitHub Pages مجاناً

1. ارفع محتويات هذا المستودع إلى حسابك على GitHub في مستودع عام (`Public Repository`).
2. ادخل إلى `Settings` ثم `Pages`.
3. تحت قسم `Build and deployment`، اختر `GitHub Actions` (أو اختر الفرع `main` والمجلد `/root`).
4. سيعمل الموقع فوراً على الرابط الساكن المجاني الخاص بك، وسيقوم ملف `.github/workflows/deploy-pages.yml` بمزامنة بيانات الهلال تلقائياً.
